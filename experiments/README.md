# Experiments — папка для экспериментов

Эта папка предназначена для **временных файлов**, разведки и проверки идей.

## Главное место для эталонов

**`design/etalon/`** — канонические источники (dim-kava-education-visual, stitch_lesson_view).  
**`design/reference/`** — HTML-копии для Django (см. design/README.md).

> `stitch_output/` устарел — эталон перенесён в `design/etalon/`. Можно удалить.

## Правила

1. **Временность** — всё, что здесь, считается временным.
2. **После проверки:**
   - Если идея подтвердилась → переносим код/структуру в основную кодовую базу.
   - Если нет → удаляем.
3. **Не влияет на прод** — код в experiments/ не подключается к production.
4. **Именование** — использовать префиксы: `exp_`, `scratch_`, `WIP_` для ясности.

## Примеры использования

- `scratch_api_design.md` — набросок API перед реализацией
- `exp_tailwind_config/` — проверка конфига Tailwind перед внедрением
- `WIP_search_alternatives.md` — сравнение подходов к поиску (PostgreSQL FTS vs Elasticsearch)

## Структура (по желанию)

```
experiments/
├── temp/       # Самые временные файлы
├── scratch/    # Черновики, наброски
└── README.md   # этот файл
```

Папки `temp/` и `scratch/` можно добавить в .gitignore, если не хотите коммитить их содержимое.
