## Ролевые инструкции (как пользоваться системой)

- `ROLE_GUIDE_CANDIDATE.md` — инструкция для кандидата (регистрация, доступ, обучение).
- `ROLE_GUIDE_EMPLOYEE.md` — инструкция для сотрудника (профиль, обучение, ILP, обратная связь).
- `ROLE_GUIDE_HR.md` — инструкция для HR (кандидаты, HR Hub, модерация, контент, мониторинг).
- `ROLE_GUIDE_ADMIN.md` — инструкция для администратора (окружение, права, поддержка, инциденты).
