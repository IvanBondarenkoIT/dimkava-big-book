# TOP გაყიდვები — грузинский шаблон для HR / AI

При полном прогоне (недельный TOP) добавляем **+1 сообщение на грузинском** по этому шаблону.

## Как пользоваться

1. Подставить **даты периода** и **цифры / точки / смены** (их обычно уже знаете из отчёта).
2. Оставить **имена пустыми** (`________`) — HR дописывает из табеля / графика.
3. Telegram-теги (`@...`) — тоже из табеля, если нужны; иначе удалить.
4. Не переводить заново текст блоков — менять только плейсхолдеры.

Плейсхолдеры в фигурных скобках `{...}` — подставляются при прогоне.  
`________` — имена сотрудников (вручную).

---

## Шаблон (копировать в Telegram / чат)

```
TOP გაყიდვები ({DATE_FROM} – {DATE_TO})

TOP 2 ცვლა სალაროს გეგმის შესრულების მიხედვით (ყავის აპარატების გაყიდვების გარეშე):

🥇 I ადგილი: {PLAN_1_LOCATION} — {PLAN_1_DATE} — {PLAN_1_SHIFT} — {PLAN_1_AMOUNT} ლარი ________

🥈 II ადგილი: {PLAN_2_LOCATION} — {PLAN_2_DATE} — {PLAN_2_SHIFT} — {PLAN_2_AMOUNT} ლარი ________

TOP 2 ცვლა გაყიდული ჭიქების რაოდენობის მიხედვით:

🥇 I ადგილი: {CUPS_1_LOCATION} — {CUPS_1_DATE} — {CUPS_1_SHIFT} — {CUPS_1_AMOUNT} ჭიქა ________

🥈 II ადგილი: {CUPS_2_LOCATION} — {CUPS_2_DATE} — {CUPS_2_SHIFT} — {CUPS_2_AMOUNT} ჭიქა ________

TOP 2 ცვლა გაყიდული ყავის რაოდენობის მიხედვით (კილოგრამებში):

🥇 I ადგილი: {KG_1_LOCATION} — {KG_1_DATE} — {KG_1_SHIFT} — {KG_1_AMOUNT} კგ ________

🥈 II ადგილი: {KG_2_LOCATION} — {KG_2_DATE} — {KG_2_SHIFT} — {KG_2_AMOUNT} კგ ________
```

### Значения смены (готовые формулировки)

| Код | Текст в сообщении |
|-----|-------------------|
| `full_day` | `სრული დღე (კალენდარული დღის ყველა გაყიდვა)` |
| `morning` | `დილის ცვლა (16:00 საათამდე, ცვლის გადაბარებამდე)` |
| `evening` | `საღამოს ცვლა (16:00-დან, ცვლის მიღების შემდეგ)` *(при необходимости)* |

## Чеклист для AI при полном прогоне

- [ ] Сгенерировать RU/EN (если нужны) как обычно
- [ ] **+1 сообщение KA** строго по шаблону выше
- [ ] Даты, точки, смены, суммы, кг, чашки — из отчёта
- [ ] Имена и `@telegram` — **не выдумывать**, оставить `________` для HR из табеля
- [ ] Не менять формулировки блоков TOP 2 (план / ჭიქა / კგ)
